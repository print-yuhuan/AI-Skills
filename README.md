# AI-Skills

个人 AI Skills 仓库，用于保存、复用和持续完善实际任务中积累的技能。后续会逐步加入不同领域的 Skills，每项技能都以独立目录维护，包含任务流程、判断依据，以及按需提供的参考资料和工具脚本。

## 技能索引

| Skill | 用途 | 文档入口 |
| --- | --- | --- |
| `android-apk-rework` | Android APK 反编译与修改：去广告、客户端 VIP/视频权限、启动等待与弹窗处理、签名自校验、重打包签名及闪退排查 | [SKILL.md](android-apk-rework/SKILL.md) |

## 仓库结构

```text
AI-Skills/
├── README.md
└── android-apk-rework/
    ├── SKILL.md          # 技能说明、适用场景和执行流程
    ├── agents/           # AI 工具的技能展示与调用配置
    ├── references/       # 专题资料、操作示例和案例复盘
    └── scripts/          # 可复用工具脚本
```

每个技能目录的文档入口是 `SKILL.md`，不单独维护 README。`agents/`、`references/` 和 `scripts/` 按实际需要提供；后续新增技能与现有技能并列放在仓库根目录。

## 使用方式

1. 从技能索引选择需要的 Skill，阅读对应 `SKILL.md`，确认适用场景、输入和执行流程。
2. 将完整技能目录导入支持 Skills 的 AI 工具，具体安装位置和调用方式遵循该工具的说明。也可以直接让 AI 阅读 `SKILL.md`，并提供它引用的资料和脚本。
3. 提供本次任务的目标、输入文件或项目路径及输出要求；执行时按需读取参考资料，保留实际验证结果。

以支持 `$技能名称` 调用的环境为例：

```text
使用 $android-apk-rework 处理「APK 文件或目录路径」：
去除广告，修改客户端 VIP/视频权限限制，取消开屏等待及公告、软件推荐弹窗，处理签名自校验。保留原包，交付签名 APK、补丁清单和实际验证结果。
```

具体修改范围由每次任务的要求决定；执行细节和验证边界见对应技能文档。

## 新增与维护 Skill

- 使用简洁、稳定的目录名称，例如 `example-skill`，每项技能独立维护。
- 在 `SKILL.md` 中定义名称、适用场景、输入、流程和交付要求，将较长的专题资料放入 `references/`。
- 工具脚本放入 `scripts/`，说明依赖、用法和验证范围，验证后再提交。
- 只保存复用所需的说明、配置和资源；任务产生的安装包、临时分析结果和运行日志保留在相应项目中。
- 新增或调整技能后，同步更新本页的技能索引。
- 提交说明使用简体中文，准确概括本次新增、修改或修复的内容。

后续维护时，先同步远程，再新增或更新技能并提交推送，例如：

```bash
git pull --ff-only
# 新增 example-skill/ 并更新 README.md
git add README.md example-skill/
git commit -m "新增示例技能"
git push
```

目录和提交说明按实际变更替换。现有技能的改进也通过同样流程持续维护。
