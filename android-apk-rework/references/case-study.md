# 本次任务完整过程与可复用结论

历史案例用于解释决策，不是未来 APK 的固定地址模板，无需历史目录即可理解。

## 需求和基线

用户要求去广告、VIP/视频权限修改，补充取消开屏强制等待、入场公告，再对三个类似 APK 执行同类任务。工作中保留原包，修改真实判断，沿用修改版签名，区分服务端限制。

分别建立清单/工作目录。三个包是 arm64 Flutter，Dart 分别为 3.12.2 stable、3.12 beta、3.2.6；相似界面不允许共用地址和 ABI。

## 第一版

使用现有 Android SDK/Java/Apktool，WSL 构建对应 Blutter，按包成对提取 libapp/libflutter，生成汇编、对象池和引用索引。

从响应字段追踪 JSON 解析和最终赋值，确认 Smi/native 整数与 canonical bool；修改实际权限谓词和存储。广告从配置/列表及展示入口处理，公告查首页/缓存。启动保留已识别的初始化并尝试取消计时。

建立 ELF VA 映射与原指令 guard，替换目标库，保留其他成员，zipalign 后签名。通过 CRC、包比对、签名和关键 ARM64 模拟；第一版三包分别有 14、21、18 处 native 指令修改。

缺真机完整验证，交付记录了运行/服务端限制。静态检查仍遗漏了后续两个问题。

## 用户反馈与定位

用户反馈推荐弹窗仍在，旧 Dart 样本在启动页退出，其余无新异常。确认退出阶段后，重点查 Android 外壳与启动，而非播放器。

推荐弹窗是独立的应用/图片推广服务，原广告列表清空未覆盖。追踪列表、缓存、首页调度及展示，在专用 async 入口转到合法完成路径，同时跳过缓存内容。

隔离模拟器中，第一版在 Flutter 前连续 killProcess，原版能到渲染。反编译外壳发现 IntegrityProvider 仍比较原版证书，重新签名触发主动退出；Android 签名有效不能替代应用自身校验。

## 修正和中间失败

同步预期证书摘要。曾等长直接替换 DEX 的 Base64 字符串并重算 checksum，但 ART 报 Out-of-order string_ids，后续显示 provider 类找不到；这个中间包未交付。改为 Smali 修改、重新组装、再反编译逐类比对，2566 类与修改后源一致。

同时撤回第一版“不可达公告体作 helper、跨函数复用导航尾部”的方案。指令模拟通过不保证 VM 栈图及初始化顺序；没有日志证明它是本次证书退出的根因，不能混为已证实原因。恢复原调用/帧，用短周期检查 ready，未就绪不递减计数或取消。

## 最终验证与边界

两份修正版沿用密钥，分别有 22、15 处 native 修改，后一包另有一个重组 DEX；无关会员、广告、播放补丁保留。

通过包比对、CRC、签名、对齐、DEX checksum/重反编译，及推荐返回和 ready/pending、路由 lazy/eager 四组合模拟。精选可安装并覆盖同签名修改版，越过证书检查到 Flutter 渲染。

原版和修正版都在同一 x86 ARM 翻译层发生 raster SIGILL，环境无法完成首页/播放，也不能宣称真机正常。最终交付修正包、清单、验证与限制说明，保留原包/首版。

## 提炼后的决策

- 早查启动自校验，Flutter 包也查 DEX。
- 独立追踪推荐/图片推广与缓存调度。
- 用调用方确定权限 bool，修改播放拦截而非会员标识。
- 字符串改动走 DEX assembler，等长/checksum 不足以证明结构。
- 优先原函数/回调，软件栈模拟不能为跨函数 VM 安全背书。
- 分开记录静态、包、模拟、安装、启动与播放证据。
- 围绕用户触发和日志修正，保留正常功能/签名，清晰输出新版本。

## 多款返修中补充的可复用经验

后续返修出现“基础会员标识已显示，试看/金币视频仍失败”及推荐列表残留。把故障逐款绑定输入与触发路径后，发现既有固定赋值会压低真实会员值，也发现不同卡产品可能共享相同等级。取得目标卡数字后可修正客户端等级处理，但数值吻合不能证明目标卡的模块、有效期和服务端完整资源已生效。

软件推荐存在独立请求，广告列表为空仍会重新填充另一缓存集合。在保留原缓存清空、刷新与异步完成的路径上跳过该请求，比只修改渲染或响应字段更能覆盖多轮启动。缓存列表的实际类型和写屏障需要保留，指令桩测试不代替 Dart VM 运行。

运行诊断中遇到混淆 AXML、Windows 汇编文件名大小写碰撞、有符号 Smi 误读和重签后 provider 拦截。临时诊断包与正式包分开；只有证明布局和引用有效才改诊断 Manifest，并确认 Android 实际接受调试标志。采集仅保留卡名/等级元数据，不能把会话或媒体数据加入技能。

一个 Kotlin 线路桥接中间版本在编译时未暴露暂停标记描述符不匹配，实际 ART 报字段错误。按交付 APK 的真实 enum 字段重编译，并用实际类验证同步/挂起及错误路径后，详情崩溃得到修正；真实访客仍被 VIP 提示拦截，不能把桥接用例通过称为完整播放修复。

部分新包通过签名、安装、启动或页面导航，仍未解决全部最高权益与完整播放。多轮输出应保留这一边界，更新当前修订索引并区分仍复现与未验证，不把生成更多签名包当成完成返修。具体操作分别见会员/播放与隔离诊断参考文档。
